
Project Charter: Recruitment & Hiring Management System

What problem does it solve, and for whom?

A single company needs one centralized platform to manage its recruitment process.

The system allows recruiters to post job openings, review candidates,
and update application statuses. Candidates can register, maintain
their profiles, browse available jobs, apply, and track their applications.

The system has three roles:

1. Candidate
   - Register and log in.
   - Maintain a reusable candidate profile.
   - Browse and filter available jobs.
   - Apply for jobs.
   - View application status.

2. Admin / Recruiter
   - Log in.
   - Create, edit, view, and close jobs.
   - View applicants for each job.
   - Filter applications by job and status.
   - View candidate details and resumes.
   - Update application status.

3. Super Admin
   - Manage Admin accounts.
   - View and deactivate candidates.
   - Manage all jobs.
   - Soft-delete or deactivate jobs.

Business Rules:
- Only Super Admin can create and manage Admin accounts.
- Admin and Super Admin can create and edit jobs.
- Candidates cannot apply twice for the same job.
- Closed jobs cannot accept applications.
- Deactivated accounts cannot access the system.
- Records are deactivated instead of permanently deleted.
- Candidate profiles can be reused across applications.

Project Limitations:
- Single-company recruitment system.
- No interview scheduling.
- No application status history.
- No multi-company support.
- Dashboard functionality will be implemented in a future stage.
